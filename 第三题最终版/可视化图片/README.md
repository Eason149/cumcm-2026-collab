# 第三题测试可视化

## 图件

- `01_最近三次正式测试总览`：效率横向条形图与三次机器人路径；
- `02_最近三次耗时构成`：按移动、测向、频道切换、成功清除和失败清除分解每源虚拟时间；
- `03`—`05`：三次测试的单案例高分辨率路径图。

每张图同时提供 320 dpi PNG 和矢量 PDF。

## 正式测试前模拟数据图件

- `06_模拟测试代表案例总览`：对正式测试前 19 次完整模拟记录按干扰源数量分组，在 10—16 源的每组中选取平均清除时间最短的案例，给出效率条形图和 7 幅轨迹图；所选案例合计成功清除 91/91 个干扰源；
- `07_模拟测试清除效率分布`：展示 19 次完整模拟测试的每源耗时、各组最佳值以及 200 s/源参考线；
- `08_模拟测试分组耗时构成`：按干扰源数量展示移动、测向、频道切换、成功清除和失败清除的平均每源耗时；
- `09_模拟测试测向响应构成`：展示无信号、方向响应和近距响应的平均每源次数；
- `10_移动距离与清除效率关系`：展示累计移动距离与每源耗时之间的样本关系；
- `11`—`17`：10—16 源各组最佳案例的单案例高分辨率轨迹图。

这部分共使用 19 次完整模拟测试、246 个干扰源。全部样本的加权平均耗时为 227.79 s/源；代表案例总览使用的是分组最佳样本，不能代替全部样本的总体统计。

## 数据来源与口径

数据来自：

```text
D:\Cumcm\第三题_开发测试工具\logs\q3_v5_20260913_010525_13abbda6
D:\Cumcm\第三题_开发测试工具\logs\q3_v5_20260913_010657_58b3448c
D:\Cumcm\第三题_开发测试工具\logs\q3_v5_20260913_010746_8a62cda6
```

机器人轨迹由 `actions.jsonl` 中按请求顺序排列的 `/measure` 与 `/clear` 坐标生成，连续重复坐标在绘图时合并；搜索站、联合探测点和专门定位点来自 `result.json` 的观测用途记录。

星形点表示返回 `clear_result=success` 的清除动作位置。官方日志未提供真实干扰源坐标，因此星形点不能称为“真实源位置”。路径图只展示移动与动作位置，不展示接收覆盖带。
